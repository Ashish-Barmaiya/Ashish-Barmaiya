## What I'm building

### [Torus](https://github.com/Ashish-Barmaiya/torus-proxy)

A Layer 7 reverse proxy and edge API gateway built in Go.

Torus is my long-running systems project for exploring the engineering behind modern networking infrastructure — concurrency, runtime lifecycle, graceful shutdown, configuration reloads, health-aware routing, and performance.

It started as a Node.js/TypeScript implementation and evolved into a Go-based systems-engineering project.

> **Build it. Measure it. Understand it. Document it.**
